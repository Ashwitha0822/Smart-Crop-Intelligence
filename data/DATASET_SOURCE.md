# Dataset source

Primary source: Kaggle Crop Recommendation Dataset.

Kaggle references:
- https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset
- https://www.kaggle.com/siddharthss/crop-recommendation-dataset

The commonly used 2,200-row version contains N, P, K, temperature, humidity, ph, rainfall and label. The dataset description says it was built by augmenting rainfall, climate and fertilizer data available for India.

Download it through the Kaggle API using `download_kaggle_dataset.py`. Check the Kaggle dataset page for the current license/terms before redistribution.
